## Установка

### 1. ⬇️ Скачать

**[Открыть страницу загрузок →](https://github.com/Slake1301/ClickForge/releases/latest)**

На странице выпуска найдите раздел **Assets** и выберите один из двух установщиков:

| Установщик | Для чего |
| --- | --- |
| `ClickForge-Setup-x64.exe` | Полная версия с мультикликером, статистикой, темами и справкой |
| `ClickForge-Lite-Setup-x64.exe` | Компактная версия для одиночных кликов |

> [!NOTE]
> Установщики и исходники приложения доступны без входа в GitHub.

### 2. 🛠️ Установить

Дважды щёлкните по скачанному EXE и пройдите мастер установки. Если нужен ярлык на рабочем столе, отметьте соответствующий пункт. **Git, PowerShell и отдельная установка .NET не нужны.** Полную версию и Lite можно установить рядом.

### 3. ▶️ Запустить

Откройте меню **«Пуск»** и найдите **ClickForge** или **ClickForge Lite**. Если вы создали ярлык, можно запустить приложение с рабочего стола.

> [!TIP]
> **Обновляете приложение?** Закройте его и запустите новый установщик той же версии продукта поверх установленной копии. У полной версии и Lite свои ярлыки, папки и настройки.

## Какую версию выбрать

> [!TIP]
> **Выбирайте Lite** для одиночных кликов по курсору. **Выбирайте ClickForge**, если нужны фиксированные точки, мультикликер, статистика или настройка оформления.

| Возможность | ClickForge | Lite |
| --- | :---: | :---: |
| Пять кнопок мыши, включая «Назад» и «Вперёд» | ✓ | ✓ |
| Одиночные клики по текущему курсору | ✓ | ✓ |
| Количество кликов или повторы до остановки | ✓ | ✓ |
| Своя клавиша или кнопка мыши, одно или два нажатия | ✓ | ✓ |
| Двойной и тройной клик, удержание и отпускание | ✓ | — |
| Фиксированная точка, случайная задержка и ограничение по времени | ✓ | — |
| Мультикликер и статистика | ✓ | — |
| Светлая и тёмная темы, акцентный цвет, встроенная справка | ✓ | — |
| Горячая кнопка по умолчанию | **F6** | **F8** |
| Аварийная остановка | **F10** | **F11** |

## Быстрый старт

### 🖱️ ClickForge · полная версия

#### 1. ▶️ Сделайте три пробных клика

Откройте **«Автокликер»** и выставьте параметры:

| Параметр | Для первого запуска |
| --- | --- |
| Кнопка мыши | **Левая** |
| Тип клика | **Одиночный клик** |
| Интервал | **1000 мс** |
| Случайный интервал | **Выключен** |
| Позиция | **Следовать за курсором** |
| Режим повтора | **По количеству повторений → 3** |

Наведите курсор на пустую область тестового окна и нажмите **F6**. После трёх кликов программа остановится. На **«Главной»** можно сверить статус и счётчик «Клики за запуск».

> [!IMPORTANT]
> По умолчанию **F6** запускает и останавливает, **F7** ставит на паузу и продолжает, **F10** аварийно останавливает выполнение. Если меняли кнопку запуска, посмотрите текущее назначение на «Главной».

#### 2. ⚡ Настройте скорость

В блоке **«Тайминг»** уменьшите **«Интервал, мс»**. Например, замените **1000** на **250** и снова сделайте три пробных клика. При включённом случайном интервале программа выбирает задержку между указанным интервалом и максимальным значением. Удержание кнопки тоже занимает время, поэтому фактический CPS может отличаться от расчёта по одному интервалу.

#### 3. 📍 Зафиксируйте точку

В блоке **«Позиция»** нажмите **«Выбрать позицию через 3 секунды»**, наведите курсор на цель и дождитесь захвата. Проверьте **X** и **Y**. Теперь при запуске кликер будет использовать эту точку, даже если до запуска вы отвели курсор. Чтобы вернуться к обычному режиму, выберите **«Следовать за курсором»**.

#### 4. 🔁 Выполните последовательность

1. Откройте **«Мультикликер»** и дважды нажмите **«Добавить текущую точку»**.
2. Задайте разные **X** и **Y** для двух безопасных точек. У первой строки укажите задержку **500 мс**, у второй — **1000 мс**.
3. Оставьте флажки у нужных строк и нажмите **«Выполнить 1 цикл»**. Отмеченные точки выполнятся **сверху вниз**, с задержкой после каждой.

### 🪶 ClickForge Lite

1. Выберите кнопку мыши, интервал и число кликов. Для первой проверки подойдут **3 клика с интервалом 1000 мс**.
2. Наведите курсор на цель и нажмите **F8**. Если запускаете кнопкой окна, у вас будет **3 секунды**, чтобы перевести курсор.
3. Нажмите **F11** или кнопку **«Остановить»**, чтобы прекратить выполнение.

### ⌨️ Как изменить горячую кнопку

В полной версии откройте **«Настройки»** и выберите функциональную клавишу или **«Ввести кнопку самому…»**, затем нажмите **«Применить клавишу»**. В Lite нажмите кнопку **«F8 · изменить»** или кнопку с текущим назначением.

| Режим | Как срабатывает |
| --- | --- |
| **Одно нажатие** | Нажмите назначенную кнопку один раз. |
| **Два нажатия** | Нажмите, отпустите и снова нажмите ту же кнопку в пределах **300 мс**. Удержание и другая кнопка между нажатиями сбрасывают попытку. |

> [!NOTE]
> Назначения глобальные. Если обе версии открыты одновременно, назначьте им разные кнопки запуска.

## Настройки и данные

- **🎨 Оформление.** В полной версии тема и акцент меняются на левой панели и применяются сразу.
- **↩️ Сброс.** Кнопка **«Сбросить настройки»** в полной версии восстанавливает параметры и точки мультикликера. Статистика сохраняется.
- **💾 Где хранятся настройки.** Полная версия использует `%LocalAppData%\ClickForge`, Lite — `%LocalAppData%\ClickForge Lite`. Lite сохраняет выбор при закрытии окна.
