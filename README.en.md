# ClickForge

[Русский](README.md) · **English**

**A free Windows autoclicker with a compact Lite edition and a full edition for click sequences.**

**[⬇️ Download for Windows x64](https://github.com/Slake1301/ClickForge/releases/latest)**

## Choose your edition

| | ClickForge | ClickForge Lite |
| --- | --- | --- |
| **Installer** | `ClickForge-Setup-x64.exe` | `ClickForge-Lite-Setup-x64.exe` |
| **Best for** | Fixed points, click sequences, statistics and themes | Simple clicks at the cursor in a compact window |
| **Default start / stop** | **F6** | **F8** |
| **Emergency stop** | **F10** | **F11** |

Both editions support a custom keyboard or mouse button as the start shortcut, with one or two presses. You can install both alongside each other.

## Install and try it

1. Open the [latest release](https://github.com/Slake1301/ClickForge/releases/latest) and download the EXE for your edition under **Assets**.
2. Run the installer and open ClickForge from the Windows Start menu. A separate .NET installation is unnecessary.
3. For a first test, select the left mouse button, a **1000 ms** interval and **3 clicks**. Point at a safe area and press the default start key.

Starting with version 0.2.20, choose **English** under **Настройки → Язык / Language** in the full edition or at the bottom of the Lite window. Restart the app to apply the language. Your choice is kept between launches; you can switch back by selecting **Русский**.
